Handed back to Debian

Loading…

Where Debian itself already ships a tool at its latest upstream version, we stop publishing that suite and hand it back — Debian's copy is current and carries full Debian QA. Every other suite keeps shipping and the package is not retired, so nobody loses a route to the current version. These are wins: each one is a suite this channel no longer has to cover.
